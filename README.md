# Bytefetch
A cli that calculate the project languages distribution percentages and measure the file size.

**This package only for Mac and Linux**

## Usage
1. Run the tool.
```
bytefetch -r
```
2. Update the tool.
```
bytefetch -u
```
3. For kilobyte.
```
bytefetch -r -kb
```
4. for megabyte.
```
bytefetch -r -mb
```
5. For help.
```
bytefetch --help
```
